# Moku — Dynamic Moku для Windows

## Запуск из исходников
    cd Island
    dotnet run -c Release

## Как получить Moku.exe
1. Поставь .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Запусти build.bat (или команду ниже в папке проекта)
       dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
3. Готовый файл: publish\Moku.exe (маленький, ~1–3 МБ).
   На других ПК нужен .NET 8 Desktop Runtime.
   Чтобы работал везде без установки .NET, замени --self-contained false на true (файл ~70 МБ).

## Управление (2.12.1)
- Клик по острову или **Alt+Space** — раскрыть / свернуть; Esc или клик мимо — свернуть.
- Настройки → Общие → Горячая клавиша → Изменить: своё сочетание или одна клавиша (например F8). Esc отменяет запись; занятая привязка не заменяет прежнюю. Пресетов и трея нет.
- **Настройки → Главная → На Главной показывать**: выбери **Буфер обмена** или **Запущенные приложения**. На самой Главной нет переключателя и кнопок «Свернуть всё / Развернуть всё».
- У запущенных приложений остались группы окон, точки и превью при наведении. Рамка превью и само изображение скругляются общей настройкой; свёрнутые и защищённые окна могут не дать картинку. ПКМ у группы с несколькими окнами позволяет выбрать окно.
- Обычный клик по приложению восстанавливает/активирует существующее окно, либо запускает его, если процесса ещё нет. Быстрые повторные запуски блокируются. ПКМ по плитке → **Открыть** или **Запустить от имени администратора** (для поддерживаемых типов; Windows запрашивает UAC).
- **Приложения → Добавить файл**: можно выбрать несколько EXE, ярлыков, BAT/CMD/PS1, изображений, DLL и других файлов. Документы открываются своей программой Windows. DLL можно хранить в списке, но она не становится самостоятельной программой. Скрипты запускаются из своей папки, без изменения политики PowerShell.
- **Создать папку** создаёт в том числе пустую виртуальную папку. Перетащи в неё плитку; крестик внутри папки возвращает файл в корень. ПКМ → переименовать/удалить папку; удаление не трогает файлы на диске. Папки можно перетаскивать и переставлять вместе с приложениями.
- ПКМ по плитке → Размер плитки: 1×1, 2×1, 2×2. Раскладка учитывает обе оси и перенос у края.
- Список доступных игр **Steam раскрывается/сворачивается стрелкой прямо в «Приложениях»**. Плюс добавляет выбранную игру; сканирование не добавляет остальные автоматически. Состояние стрелки сохраняется, отдельных настроек скрытых игр больше нет. Проверка установленных игр раз в минуту обновляет только предложения.
- Меню ПКМ, их подменю и превью оформлены в стиле Moku: тёмная поверхность с оттенком темы, без стандартного белого меню. Общая настройка скругления применяется и к ним.
- Подсветка кнопок быстрого запуска справа на Главной не удерживается завершившейся анимацией нажатия.

Подробнее: [изменения и проверки 2.12.1](CHANGELOG_2.12.1.md); [история 2.12.0](CHANGELOG_2.12.md).

## Скриншоты (плитка «Область»)
- Выдели область мышью → внизу появится панель: Перо, Стрелка, Рамка, Маркер, цвета, толщина
- Enter или Ctrl+C — копировать в буфер, Ctrl+S — сохранить PNG, Ctrl+Z — отменить, Esc — закрыть
- «Экран» — снимок всего экрана сразу в буфер обмена

## Настройки (вкладка «Настройки»)
Положение (слева / по центру / справа), отступ сверху, размер острова, цвет для музыки и событий,
автозапуск, язык. Хранятся в %APPDATA%\Moku\settings.json

Расширенные настройки (v2.7), применяются сразу без перезапуска:
- **Анимация** — «желейность» острова 0–200 % (0 — без растяжения), скорость анимации 50–200 %
- **Глаза** — следят за курсором, дальность взгляда 50–150 %, эмоции, засыпать ночью, танцевать под музыку, энергия танца 0–200 %
- **Музыка** — волна вкл/выкл, высота волны 30–150 %
- **Уведомления** — тост при копировании, тост при смене трека
- **Поведение** — запись собственной горячей клавиши (по умолчанию Alt+Space),
  длина истории буфера (плавный ползунок 5–200 записей), прятаться в полноэкранных играх
- Кнопка «Сбросить эти настройки» возвращает значения по умолчанию
- Все ползунки плавные (без шага), клик по дорожке ставит бегунок в точку; настройки сохраняются, когда ползунок отпустили
- Сдвиг по X / Y — поле с кнопками −/+ (Shift — шаг 10) и колёсиком мыши

Что нового в 2.11: настройки разложены по разделам — меню из карточек («Цвета и тема», «Положение и размер», «Глаза»,
«Анимации», «Свёрнутый вид», «Музыка и уведомления», «Приложения», «Общие»), поиск по настройкам и сброс отдельного раздела.

Что нового в 2.10: формы глаз (овалы, круглые, точки, аниме, «^ ^», робот, кошачьи), их размер, расстояние, цвет,
свечение и частота моргания; стили появления «Пружина / Плавно / Капля» и отдельные скорости раскрытия и уведомлений;
выбор, что показывать в свёрнутом острове (время, дата, погода, батарея, CPU, RAM), 12/24 ч и секунды, таймер и
секундомер; размер плиток приложений, папки, свои подписи и иконки.

Что нового в 2.9: настоящие иконки Steam-игр (как у ярлыков), крестик удаления на плитках приложений,
перестановка плиток перетаскиванием, плавное появление/исчезновение острова в играх, «стеклянная» прозрачность
(кромка и блик остаются) и полностью переведённые уведомления.

Что нового в 2.8: обложка трека в раскрытом острове и маленькая — в свёрнутом, оценка темпа (BPM) и «танец» глаз
под темп, новые эмоции (умиление с румянцем, когда глаза «гладят» курсором; любопытство; скука и зевота; грусть).

## Жидкий остров
- Вся анимация острова и глаз — на пружинной физике: остров «растекается» с отскоком, тянется по направлению движения и мягко дрожит при остановке; новая цель посреди движения подхватывается без рывка.
- Глаза: плавное слежение за курсором и быстрые «саккады» с перелётом, вытягивание и наклон при движении, моргание с упругим отскоком (иногда двойное), подпрыгивание в такт бочке.
- Эмоции: радость (копирование, скриншот, музыка), восторг (новый трек), спокойствие (пауза), внимание (курсор над островом), испуг (ошибка или резкий взмах мышью рядом), сонливость (глубокая ночь и долгий простой).
- Пока играет музыка, нижний край острова превращается в «слаймовую» волну цвета акцента (в свёрнутом и в раскрытом виде).
- Слева в свёрнутом острове — глазки: следят за курсором, моргают, под музыку покачиваются, а если мышь долго стоит — засыпают.
- Справа — время и значок погоды с температурой (Open-Meteo, место определяется по IP, обновление раз в 15 минут; если сеть недоступна, приложение повторяет попытку и показывает последнее сохранённое значение).

## Производительность и стабильность
- Убрана принудительная полная сборка мусора и очистка working set из UI-потока.
- Движение волны и слежение глаз синхронизированы с кадрами WPF-композиции и используют реальный delta time.
- Clipboard обрабатывается с debounce и повторными попытками, если его временно удерживает другое приложение.
- Погода повторяет запросы при ошибках сети; последнее успешное значение хранится в `%APPDATA%\Moku\weather-cache.json`.
- Иконка системного трея освобождается при штатном завершении приложения.


## Установщик и публикация релиза

### Собрать установщик Windows x64
1. Установи **.NET 8 SDK**. Inno Setup не требуется: установщик Moku — отдельное WPF-приложение.
2. Открой папку `Island` и запусти `build-release.bat`.
3. Получишь два файла:
   - `Island\\publish\\Moku.exe` — автономное приложение (не требует установленного .NET Runtime).
   - `Island\\release\\Moku-Setup-2.12.0-x64.exe` — полноценный установщик с мастером установки, ярлыками, автозапуском и деинсталляцией через «Программы и компоненты».

### Опубликовать на GitHub Releases
Чтобы опубликовать релиз, собери файлы командой выше и приложи `Island\\publish\\Moku.exe` и `Island\\release\\Moku-Setup-2.12.0-x64.exe` к GitHub Release. Перед публичным релизом рекомендуется подписать EXE/установщик Authenticode-сертификатом, чтобы Windows SmartScreen меньше предупреждал пользователей.


## Язык интерфейса
Настройки → Общие → Язык: English / Русский. Выбор сохраняется в `%APPDATA%\Moku\settings.json`. Редактор скриншотов использует выбранный язык; установщик также предлагает оба языка.

## Проверки
`dotnet run --project Island.Tests/Island.Tests.csproj -c Release` — 429 проверок правил раскладки, настроек, миграции и защиты повторного запуска. Это не проверка Win32 и не интерактивное тестирование Windows.
Полная WPF-сборка приложения и установщика выполняется в GitHub Actions на Windows. Артефакт CI требует .NET 8 Desktop Runtime и не является проверенным самостоятельным установщиком. Для самостоятельного установщика используй `Island/build-release.bat` на Windows.
