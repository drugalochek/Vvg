# Moku 2.12.3

## Быстрый доступ справа на Главной
- Поиск окна для активации отделён от списка окон и превью: отсутствие заголовка, владельцы окон и APP-cloaking не исключают свёрнутое окно.
- Поиск учитывает HWND хоста UWP, отдаёт предпочтение свёрнутым основным окнам и не путает рабочий стол с Проводником.
- Если HWND приостановленного Калькулятора недоступен, используется зарегистрированная активация `calculator:`, а не проверка процесса `calc.exe` с тупиковым сообщением.
- Тесты Windows используют также отдельный процесс с именем CalculatorApp.exe, у которого свёрнутое окно без заголовка/кнопки панели задач. Проверяется производственный поиск для команды calc.exe и восстановление того же HWND.

## Музыка отдельно от Discord
- Низкие, средние и высокие частоты берутся через WASAPI process-loopback только из процесса текущей медиасессии Windows и его дочерних процессов.
- Идентичность плеера передаётся из той же медиасессии, что предоставляет название и обложку. Выбор не основан на громкости общего выхода.
- При неизвестном плеере, ошибке захвата или неподдерживаемой Windows нет возврата к общему миксу: измеренные уровни остаются нулевыми.
- Смена плеера, пауза/стоп и смена процесса обновляют захват. Нужна Windows build 20348+ (в частности Windows 11). На обычной Windows 10 build 19041–19045 изолированный анализ недоступен; остальная работа Moku сохраняется.
- Изоляция на уровне приложения, не отдельной вкладки браузера: если музыка и звонок идут из одного браузерного процесса, они могут смешиваться внутри него.

Это исходники Vvg; ранее опубликованный установщик Moku 2.12.2 не заменяется этими изменениями автоматически. Windows-проверка API зависит от доступности аудиослужбы на runner; реальное прослушивание Spotify/Яндекс/браузер + Discord требует проверки на пользовательском компьютере.
