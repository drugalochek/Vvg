# Moku 2.12.2 — быстрый доступ на Главной

- Кнопки программ справа на Главной сначала ищут доступное окно приложения: свёрнутое восстанавливают, открытое активируют. Только при отсутствии окна/работающего приложения используется прежний запуск и защита от повторов.
- Кнопка «Терминал» распознаёт существующие окна Windows Terminal и PowerShell, а не только PID `powershell.exe`. Для классической консоли определяется настоящий HWND, принадлежащий `conhost.exe`; чужие консоли не выбираются только по имени хоста.
- У Калькулятора и других UWP-приложений определяется процесс содержимого за `ApplicationFrameHost`. Проводник не путается с рабочим столом.
- Восстановление выполняется через `ShowWindowAsync(SW_RESTORE)`, без принудительного разворачивания обычного окна на весь экран. При наличии видимого модального окна фокус направляется ему. Ограничение Windows на передачу фокуса не приводит к запуску копии.
- Проверки: правила распознавания быстрых действий и Windows-тест с отдельным минимизированным процессом — восстанавливается то же окно, повторное нажатие его переиспользует. Существующие проверки меню, папок, Steam и раскладки сохранены.
- Полный ручной прогон конкретных версий Проводника, Блокнота, Windows Terminal, PowerShell, Калькулятора и повышенного Диспетчера задач требуется отдельно.

Это изменение исходников Vvg. Уже загруженный установщик Moku 2.12.1 не изменялся; для публикации исправления нужна новая сборка 2.12.2.
