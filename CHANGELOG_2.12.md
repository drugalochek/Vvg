# Moku 2.12.0

## Изменения
- Окна на Главной: группы по приложениям, иконки и точки, переключение и восстановление свёрнутого окна, список окон по ПКМ, превью при наведении с безопасным тайм-аутом.
- Запуск без случайных копий: сначала поиск существующего окна и процесса, затем запуск. Ярлыки .lnk разрешаются в путь приложения; для Steam используется каталог установленной игры. Новое окно только явной командой ПКМ.
- «Свернуть всё / Развернуть всё»: хранение окон, свёрнутых самим Moku, проверка процесса и существования окна перед восстановлением.
- По умолчанию Alt+Space. Запись собственного сочетания либо отдельной клавиши. Esc — отмена, при конфликте старая привязка восстанавливается. Старые сохранённые сочетания мигрируют без сброса.
- Прозрачность при обычном окне под свёрнутым островом — отдельный переключатель. Прежний полноэкранный режим и существующий уровень прозрачности сохранены.
- Настройки Главной разделены на начальный вид и запоминание последнего выбора Буфер / Окна.
- Индивидуальные размеры плиток 1×1, 2×1, 2×2, двухмерная раскладка, перенос у края и перераскладка после перетаскивания.
- Автоматическое добавление установленных игр Steam и проверка раз в минуту на открытой вкладке Приложения. Скрытые игры сохраняются, восстановление по одной и всех.
- Удалён системный трей, сохранены темы, цвета, шрифты, размеры острова, глаза, анимации и остальные разделы.

## Проверки и честные ограничения
- 429 платформонезависимых проверок, включая 400 случайных раскладок по 60 плиток, проходят командой `dotnet run --project Island.Tests/Island.Tests.csproj -c Release`.
- Windows CI компилирует настоящий XAML/WPF и установщик с payload. Это не заменяет ручную проверку интерфейса, горячих клавиш и переключения окон на реальной Windows.
- Превью может отсутствовать у свёрнутых, защищённых, слишком больших, не отвечающих и некоторых аппаратно-ускоренных окон. Захват не блокирует UI, число одновременно выполняемых захватов ограничено двумя.
- Доступ к повышенным процессам может быть ограничен Windows. Обёртки-лаунчеры, приложения с нестандартными процессами и Steam-игры вне каталога установки могут определяться не полностью.
- Защита запуска без найденного процесса имеет тайм-аут 30 секунд: бесконечно запрещать повтор после неудачного старта нельзя.
- Сохранён существующий предел 60 приложений. Полный экран в прежнем игровом режиме определяется по основному монитору, как и до обновления.
- Программные иллюстрации показывают ожидаемое устройство интерфейса и демонстрационные данные. Они не являются снимками работающего Windows-приложения.
