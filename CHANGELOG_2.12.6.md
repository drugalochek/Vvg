# Moku 2.12.6

- Волна автоматически выбирает доступный изолированный способ анализа. Переключателя Windows 10 / Windows 11 больше нет; старый выбор в settings.json игнорируется без сброса остальных настроек.
- Идентификатор медиасессии `ru.yandex.desktop.music` сопоставляется с точными именами EXE настольной Яндекс Музыки, в том числе без установленного ярлыка. Яндекс Браузер под него не подставляется.
- Плееры с собственным desktop/Electron AppUserModelID определяются по точному идентификатору окна и зарегистрированным ярлыкам, а не только по имени EXE или идентификатору упакованного приложения.
- Звуковые сессии дочерних процессов сопоставляются с корнем дерева плеера. При неоднозначном источнике не выбирается случайное или самое громкое приложение.
- Если захват процесса запущен, но остаётся без сигнала при реально звучащей аудиосессии плеера, автоматически используется уровень этой сессии. Этот режим показывает активность, не выдумывая частотный спектр.
- Общий звук Windows и отдельные процессы Discord не подставляются вместо неизвестного источника. Звук вкладок одного браузерного дерева по-прежнему не разделяется.
- Изменения проверяются автоматическими policy- и Windows-интеграционными тестами. Реальное воспроизведение Яндекс Музыки на пользовательских Windows 10/11 требует отдельной проверки.
