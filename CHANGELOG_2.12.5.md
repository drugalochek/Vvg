# Moku 2.12.5

- Настройки → Музыка и уведомления → Режим звука Windows: ручной выбор Windows 11 / Windows 10.
- Windows 11 — изолированный частотный анализ; Windows 10 — уровень аудиосессии выбранного плеера. Совместимый режим можно включить и на Windows 11.
- Переключение применяется сразу, сохраняется между запусками и сбрасывается вместе с музыкальными настройками. Старый захват и уровни отключаются до включения нового.
- Первоначальный режим выбирается по поддержке ОС; принудительный Windows 11 на старой системе не вызывает неподдерживаемые API. При ошибке частотного захвата сохраняется изолированный совместимый fallback.
- Общий микс системы не захватывается, неизвестный плеер не заменяется посторонним процессом. Изоляция по приложению, не по вкладке браузера.
- Добавлены policy/JSON-проверки и Windows-проверки настоящего переключателя и смены backend. Для подтверждения реакции на реальный звук нужна проверка на пользовательском ПК.
