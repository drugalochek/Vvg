# Moku 2.12.1

## Главная
- Один выбранный в настройках блок: буфер обмена либо запущенные приложения. Переключатели и массовое сворачивание/восстановление убраны.
- Превью сохранены по последнему уточнению. Собственный тёмный popup и реальное обрезание изображения по общей настройке скругления. Для защищённых/свёрнутых окон возможна надпись «Превью недоступно».
- Исправлена причина залипания подсветки быстрых действий: убраны удерживающие значение анимационные часы, hover/pressed действуют только при видимости кнопки.

## Файлы и папки
- Кнопка создания папки; пустые папки, названия и смешанный порядок папок/файлов сохраняются при перезапуске. Старые папки мигрируют автоматически.
- Перенос плитки на папку, перенос обратно крестиком или на плитку «Назад», переименование. Удаление виртуальной папки возвращает содержимое в корень, не удаляя файлы с диска.
- Сами папки перетаскиваются среди плиток. Вложенность папок не добавлялась.
- Выбор нескольких файлов любых типов, включая PNG, DLL и BAT/CMD/PS1. Лимит библиотеки — 60 файлов/приложений; папки считаются отдельно.
- Обычный запуск через Windows и отдельная явная команда запуска от администратора. EXE/COM/LNK/BAT/CMD/PS1/MSI поддерживают UAC. Для PNG/DLL запуск от администратора отключён: DLL не исполняется с выдуманной точкой входа.
- BAT/CMD запускаются через системный cmd.exe из каталога скрипта; PS1 — через Windows PowerShell без обхода execution policy. Это сохраняет относительные пути к файлам пакета, в том числе у zapret-discord-youtube; сами сторонние скрипты и пакеты не менялись.
- Сохраняются восстановление существующего окна, блокировка быстрых повторов и отслеживание запущенного скрипта в текущей сессии.

## Steam и оформление
- Доступные для добавления игры собраны в раскрывающийся список в «Приложениях». Положение стрелки сохраняется. Игры добавляются вручную по плюсу; сканирование обновляет предложения, но не закрепляет всё подряд.
- Индивидуальное скрытие игр и отдельные настройки скрытых игр убраны. Уже добавленные игры не теряются; старые скрытые предложения снова доступны под общей стрелкой.
- Собственные меню ПКМ на уровне приложения, включая подменю: оттенок темы, своё выделение/разделители/неактивные пункты, общий радиус углов. Системные окна выбора файла и UAC остаются системными.
- Настройки прозрачности, глаза, шаблоны и анимации острова в этом обновлении не переделывались. Исправление детектора обычных окон в эту версию не заявляется.

## Проверка
- `dotnet run --project Island.Tests -c Release`: проверки политик запуска, переноса/сохранения папок, миграции настроек, структуры Home/Steam, шаблонов меню и 400 случайных раскладок плиток.
- Windows workflow компилирует приложение/установщик и запускает `Island.Windows.Tests`: реальные WPF-шаблоны ПКМ/подменю/tooltip, изменение радиуса на 0 и 31, обработчик клика.
- Это не полная ручная проверка Moku на пользовательском ПК: UAC, реальные окна сторонних приложений, drag-and-drop и конкретные сборки zapret требуют отдельного прогона на Windows.
